Glossary

The words every lesson uses, with the same meaning each time.

Terms are added as lessons introduce them. If a lesson uses a word differently from this page, the page wins, so tell your teacher.

Engine structure

Node
The basic building block. Each node type does one job (draw a sprite, detect collisions, play a sound). Nodes have a name, properties, and per-frame callbacks, and any node can have children. Docs
Scene
A tree of nodes saved to a .tscn file, with exactly one root node. Once saved, a scene acts like a new node type: you can drop it inside another scene as a single node. Docs
Root node
The top node of a scene. Its type usually defines what the scene is, e.g. a paddle scene's root is a CharacterBody2D.
Scene tree
The live tree of all nodes while the game runs. A game is a tree of scenes, and each scene is a tree of nodes.
Instance
One copy of a scene placed inside another. Ten bricks are ten instances of one Brick scene. Docs
Main scene
The scene Godot loads first when the game runs. Set in Project Settings.
PackedScene
A loaded .tscn file: a template, not yet a node. Get one with preload("res://…tscn") or an @export var x: PackedScene. Docs
instantiate()
Builds a fresh node tree from a PackedScene. It isn't drawn, doesn't collide, and its _ready() hasn't run until you add_child() it.
queue_free()
Deletes a node at the end of the current frame, not immediately. Until then it is still in the tree and in its groups. Docs
Group
A named tag on a node, such as "bricks". Any node can be in many groups. Use is_in_group() to check a role and get_tree().get_nodes_in_group() to find every member. Docs
class_name
Registers a script as a named type, like Ball. Variables can then be typed var b: Ball, so the type check knows its methods and signals.
Remote tab
Scene → Remote while the game runs: the live tree, including nodes made from code, with editable properties.

Input

Input action
A named input, like move_left, that any number of keys, buttons or sticks can trigger. Game code checks actions, not raw keys, so remapping and gamepad support come for free. Name actions in snake_case. Docs
Input Map
The Project Settings tab where actions are defined and bound to events. Stored in project.godot.
Input.get_axis(neg, pos)
Returns a float from −1 to 1: the strength of pos minus the strength of neg. One call gives left/right direction. Docs
Polling vs events
Polling checks input state every frame (Input.is_action_pressed), for held actions like movement. Events arrive in _input(event) once per press, for one-off actions like jump.

Physics & movement

CharacterBody2D
A body that detects collisions but has no built-in physics. Your code moves it. Use it for players, enemies, and paddles. Docs
StaticBody2D
A body that collides but never moves in response. Use it for walls and floors.
RigidBody2D
A body the physics engine simulates. You apply forces instead of setting its position.
Area2D
Detects overlaps and emits signals when bodies enter or exit. Doesn't block movement.
CollisionShape2D
The child node that gives a body or area its shape. A body with no shape collides with nothing.
Vector2
Two floats, x and y, read as an arrow from (0, 0) to (x, y). The arrow has a direction and a length; what they mean (position, velocity, size) depends on the code using it. y grows downward.
normalized()
Returns the same direction with length 1, so dir.normalized() * speed means "this way, this fast".
velocity
A CharacterBody2D property: the speed and direction in pixels per second. You set it, then call move_and_slide().
move_and_slide()
Moves the body by velocity, slides along whatever it hits, and applies the physics delta itself. Don't multiply velocity by delta before calling it. Docs
move_and_collide(motion)
Moves the body by a distance (so pass velocity * delta), stops at the first hit, and returns a KinematicCollision2D or null. Use it when you want to bounce, not slide. Docs
KinematicCollision2D
What move_and_collide returns on a hit. get_normal() gives the direction the surface faces; pass it to velocity.bounce().
Collision layer / mask
Layer: which channels an object is on. Mask: which channels it scans for. A collision happens when one object's mask includes the other's layer. Defaults are layer 1, mask 1. Docs
motion_mode
Grounded for side-view games with floors and ceilings. Floating when there's no floor (top-down games, a Breakout paddle).

Signals

Signal
An event a node announces, such as body_entered. Other nodes connect a function to it with signal.connect(func), and the emitter doesn't know who listens. Docs
Call down, signal up
A parent calls methods on its children; a child emits signals and lets the parent react. A child that calls get_parent() is tied to that one parent.

Game structure

Game state
What the game is doing right now, such as PLAYING or GAME_OVER. Hold it in one enum variable with one owner, and change it through one function, so impossible combinations can't happen. Game Programming Patterns
CanvasLayer
Draws its children on a separate layer, above the 2D scene, and ignores cameras. A Control under it anchors to the edges of the viewport the layer is in. Use it for HUDs and on-screen messages. Docs

The frame loop

Pause (get_tree().paused)
Stops the _process, _physics_process and input callbacks, and physics, of every pausable node. Paused nodes are still drawn, and method calls and signal callbacks on them still run. Docs
process_mode
Whether a node runs when the tree is paused: Inherit (the default: the same as its parent), Pausable, When Paused, Always or Disabled. If a parent is Always, every Inherit child is Always too, so set the branch that should freeze back to Pausable.
_physics_process(delta)
Runs at a fixed rate (60/s by default) before each physics step. Movement and anything touching bodies goes here.
_process(delta)
Runs once per rendered frame, which varies. Use it for visuals that don't touch physics.
delta
Seconds since the last call. Multiply per-second rates by it, unless the engine already does (see move_and_slide).

Art and textures

Texture2D
An image Godot can draw. A PNG under res:// is imported as one automatically. Commit its .import file, which holds the import settings. Docs
Texture filter
How a texture is drawn when it's scaled. Linear blends neighbouring pixels (blurry); Nearest copies the closest one (hard squares, right for pixel art). The project default doesn't reach a SubViewport, which has its own Canvas Items → Default Texture Filter.
Sprite2D
A node that draws one texture, centred on its origin by default. Use it for art that never changes size. Scale the sprite, not the physics body it belongs to. Docs
NinePatchRect
A Control that splits a texture into a 3×3 grid with four patch margins. Corners stay fixed, edges stretch along one axis, and the centre stretches both ways, so one texture fits any size. Also called 9-slice. Docs
Art scale
Screen pixels per art pixel. In Breakout it's 2: art is drawn at half size and scaled 2× with Nearest filtering. Export art at 100%, so the scaling happens in one place.
