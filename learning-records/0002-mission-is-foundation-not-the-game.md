# Mission is the foundation, not the tactics game

The learner clarified that the Ogre Battle-style game is a separate, later project. This workspace builds the Godot foundation for it. Lessons should therefore cover the breadth of the engine through toy games, not build pieces of the tactics game, and should mention the later game only when explaining why a topic matters. They also fixed the workflow: specs are small, one feature at a time, and the agent works in view so every change gets reviewed. See [[MISSION.md]].
